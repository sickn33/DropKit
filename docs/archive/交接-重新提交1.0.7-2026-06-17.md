## 如果要让这几步也全自动(给 Codex 的关键信息)

网页那几步(选 build、改元数据、提交审核)能自动化,但**需要一个 App Store Connect API 密钥**:

- 生成方式(只能账号持有人在网页做一次,约 2 分钟):
  appstoreconnect.apple.com → **用户和访问** → **集成 / 密钥(Integrations/Keys)** → 生成密钥 → 下载 `.p8` 文件,记下 **Key ID** 和 **Issuer ID**。
- 有了它之后,可用 **fastlane**(`deliver` 选 build + 改元数据 + 提交审核;`pilot` 管 build)或 App Store Connect REST API 全自动完成第 1、2、4 步。
  - 注意:**第 3 步"回复审核员"(Resolution Center 对话)**用 API 较难,通常仍需网页手动贴。
- 当前机器上**未发现**现成的 `.p8` / fastlane 配置(`密钥存储/.env` 里也没有 Apple 相关条目)。所以要么手动点完这次,要么先生成 API 密钥再自动化。

> 本次"打包+上传"已用 `xcodebuild -exportArchive ... -allowProvisioningUpdates` 跑通,**不需要 API 密钥**(借 Xcode 登录态)。只有上面网页那几步才需要密钥才能自动化。
