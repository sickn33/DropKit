# DropKit 修复 App Store 2.4.5 拒审 · 工作记录 · 2026-06-17

> 本文记录这一天从"收到拒审 + 摇晃失效 + 截图卡"到定位根因、修复、验证、入库的全过程。
> 用 systematic-debugging 流程走的:先找根因,再动手。

## 背景

1.0.6 首次提交 Mac App Store,2026-06-16 被 Apple 以 **Guideline 2.4.5 - Performance** 拒审。
同时用户实测发现两个问题:

1. **摇晃鼠标召唤搁架失效**——摇了弹不出来。
2. **截图特别卡**——用苹果原生快捷截图时响应很久(其他软件截图正常)。

用户诉求明确:摇晃是这个 App 的灵魂功能,**不接受用快捷键替代**,必须修好摇晃本身。

## 拒审原文(关键)

> **Guideline 2.4.5 - Performance**
> The app requests access to Accessibility features on macOS but does not use these features for accessibility purposes. Specifically, the app uses Accessibility features to "来检测鼠标摇晃手势". Apps may not use features designed to increase accessibility for other purposes.

Submission ID:`5482a7fc-4cc1-4f5f-abea-c5f7c00c16a5` · Review date:June 16, 2026 · 版本:1.0.6 (1.0.6)

## 根因调查

### 时间线还原(git 考古)

- 摇晃/拖拽监控的辅助功能权限检查 `guard permissionChecker()`,是 **`6bacd84` "Prepare DropKit for App Store review"**(上架准备 commit,06-10)加进去的。在此之前,`DragMonitor.start()` 直接 `NSEvent.addGlobalMonitorForEvents(matching: .leftMouseDragged)`,**没有任何权限检查**,摇晃一直能用。
- 用户实际运行的是 `/Applications/DropKit.app`(运行时证据:进程路径 + 构建时间 06-11 20:17),已是改后的版本。

### 关键技术事实(Apple 官方文档,最高权威)

`NSEvent.addGlobalMonitorForEvents` 文档原文:

> **Key-related events may only be monitored if accessibility is enabled or if your application is trusted for accessibility access.**

即:**只有"键盘相关事件"才需要辅助功能权限,鼠标事件不需要。** 而摇晃/拖拽监控用的是 `.leftMouseDragged` / `.leftMouseUp`——纯鼠标事件,本就不需要辅助功能权限。

### 结论:一个错误,两个后果

上架准备时**误判**"摇晃需要辅助功能权限",加了 `guard permissionChecker()` + 配套的"请授权辅助功能"引导窗。这一个错误同时造成:

| 后果 | 机制 |
|---|---|
| Apple 2.4.5 拒审 | App 申请了根本用不上的辅助功能权限,被判"辅助功能挪作他用" |
| 摇晃失效 | 用户没在系统设置授权辅助功能 → `guard` 直接 return,摇晃监控压根不启动 |

### 截图卡(暂搁置)

- 用户反馈卡顿是**间歇性**的("有时候卡"),关/开文件夹监控对比不出差异,无法稳定复现。
- 代码层面:`FolderMonitor` 是后台队列 + debounce 扫描,缩略图是 `QLThumbnailGenerator` 异步懒加载——按当前代码不该卡到"响应很久"。Codex 的 `b50d800 Debounce folder monitor scans` 已是减卡优化。
- 按 systematic-debugging "无法稳定复现就不归因"原则,**暂搁置**。等摇晃修好、有稳定新版本后,若仍卡,再在卡的当下直接抓进程调用栈定位。

## 验证结果(运行时证据,非推断)

- `xcodebuild test` → **11/11 通过**(含新加的 `testDragMonitorRegistersGlobalMouseMonitorsOnStart` / `testShakeDetectorRegistersGlobalMouseMonitorOnStart`)。
