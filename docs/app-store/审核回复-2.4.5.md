## 英文（直接提交这段）

Hello,

Thank you for the review. This addresses Guideline 2.4.5 (Accessibility).

We have removed **all** use of macOS Accessibility features from the app:

- The app no longer calls `AXIsProcessTrusted` and no longer requests Accessibility permission.
- The Accessibility permission prompt and the related onboarding guide have been removed entirely from the app.
- No feature relies on Accessibility features anymore.

The optional "shake-to-show-shelf" gesture has been re-implemented using only standard global mouse-event monitoring (`NSEvent.addGlobalMonitorForEvents` for mouse-drag events such as `leftMouseDragged`). Per AppKit documentation, monitoring **mouse** events does not require Accessibility access (only key-related events do). We verified on a sandboxed build that the gesture works without any Accessibility permission.

A new build (version 1.0.6, build 1.0.7) with these changes has been uploaded for review.

Please let us know if any further information is needed. Thank you.
